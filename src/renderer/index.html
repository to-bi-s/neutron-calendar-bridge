    Overview

    Calendars

    Select the calendars to be synced by Neutron Calendar Bridge.

    A calendar made with File → New Calendar belongs to this address in Proton (its key, its invitations). Calendar.app cannot say which one, so it is set here.

    Setup

    Apple Calendar

    Auto Setup

    Not set up

    Click Set Up Calendar.app and follow the steps.

    1. In System Settings → General → Device Management, double-click Neutron Calendar Bridge and click Install.

    Switch Off Reminders

    macOS turns Reminders on for every new account. Switch it off in System Settings → Internet Accounts: Proton Calendar has no tasks.

    More Details
    • On macOS 13 and 14 the profile is under Privacy & Security → Profiles.
    • The profile shows as "not verified": it was made on this Mac by the bridge, not signed by Apple, and holds only the account settings listed under "Manual Setup" below.
    • If you had added the bridge to Calendar.app by hand before, remove that account (Calendar.app → Settings → Accounts) so the calendars are not listed twice. (An account added by hand can be named there; the one from the profile cannot be renamed.)
    • The account is tied to the profile: to remove it later, remove the profile in System Settings. The profile file is kept in the app's folder for a few minutes only, because it holds the bridge's password.
    • Once connected, set up again only for another Mac user account, or after the account was removed from Calendar.app.
    • With Reminders left on, Reminders keeps asking the bridge for a task list (refused, harmless).

    Thunderbird

    Manual Setup

    Not set up

    Adds all calendars of this account to Thunderbird in one go. Click a value to copy it.

    Username -
    Location -
    Password Click to copy
    1. In Thunderbird's calendar: New Calendar → On the Network. Enter the username and location, click Find Calendars, and give the password when asked.
    2. Tick the calendars you want.
    3. For each new calendar: right-click it → Properties → Email: None.

    Email: None

    With an email identity, Thunderbird sends invitations itself, and they fail. With None, the bridge sends them, as for Calendar.app.

    More Details
    • Thunderbird checks every 30 minutes; under Properties, "Refresh Calendar: Every minute" shows changes sooner.
    • The password is the bridge's (the one Calendar.app uses), not your Proton password.
    • Guests' answers show as small icons next to each attendee when you open a meeting.
    • Thunderbird's warning to assign an email identity can be closed: the bridge takes care of invitations.
    • Proton has no categories, attachments or links field, and no privacy setting: those are dropped on save. Links in the description and "Show time as free" are kept; a Tentative status is not (Proton has none).
    • A recurring invitation is answered from the occurrence you open; the bridge passes that on as your answer for the whole series, as Proton Calendar does (Proton takes one answer per series). The Attendance entries in the context menu stay empty without an email identity.

    Manual Setup

    Untested

    The bridge is a CalDAV server on this Mac, so other calendar apps (BusyCal, Fantastical, …) should work with it too. Only Calendar.app and Thunderbird have been tried so far. Click a value to copy it.

    1. In the app, add a CalDAV account (often called "Other CalDAV", "Generic CalDAV" or "On the Network") with the server URL, username and password above.
    2. Leave SSL/TLS off: the bridge listens only on 127.0.0.1. If the app asks for server, port and path separately, use the second row; if it finds no calendars from the server URL, try the calendar home.
    3. Let the app find the calendars and tick the ones you want. Each Proton account has its own username: add one CalDAV account per Proton account.
    4. If the app can send invitations itself (an email identity or an "invitations via" setting), switch that off: the bridge emails invitations and answers through Proton.
    5. Make a test event in the app and look for it in Proton Calendar; then one in Proton and refresh the app. If the app refreshes rarely, shorten its interval.

    Tried another app?

    Please tell what worked and what did not at github.com/to-bi-s/neutron-calendar-bridge. Detailed logging (Settings) shows every request in the log; mind that it then holds private details.

    More Details
    • The password is the bridge's (the one Calendar.app uses), not your Proton password.
    • Only apps on this Mac can reach the bridge; a phone or another computer cannot.
    • Proton Calendar has no tasks: a task list (VTODO) is refused. Events, repeats, alerts, invitations and answers are supported.

      Info

      What This App Does

      Signs in to Proton, keeps an encrypted copy of your calendars on this Mac and serves it to Calendar.app, Thunderbird or any other CalDAV app, with changes flowing both ways. Your calendars are decrypted here only and never pass through anyone else's server.
